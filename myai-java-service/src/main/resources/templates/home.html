演示场景与引导工作流

这些场景用于安全地展示 MyAI 的核心能力。按钮会跳转到对应工作台并填入示例，不会自动写入敏感数据或上传文件。

记忆纠正与治理
展示 MyAI 如何识别偏好、纠正旧记忆、进入待确认队列，并在记忆页查看治理元数据。
  1. 先在聊天中声明一个普通偏好。
  2. 再使用“其实/更正”表达变化。
  3. 到记忆页查看当前/历史状态。
知识库引用问答
展示上传文档、结构化摘要、文档问答和 citation-first 回答。需要先在知识库中上传一个本地 PDF/DOCX/TXT。
  1. 进入知识库上传或选择文件。
  2. 填入问题并运行文档问答。
  3. 查看引用、摘要和证据片段。
任务执行与恢复
展示任务规划、工具执行、timeline、失败/恢复元数据和结果摘要。
  1. 将示例任务填入任务工作台。
  2. 运行同步任务或后台任务。
  3. 查看任务详情和事件时间线。
本地只读工具（MCP-style）
展示限定在演示目录内的 filesystem 只读 connector、工具策略、权限映射和调用轨迹。标准 MCP Server 互操作将在下一检查点接入。
  1. 打开任务工作台查看工具目录。
  2. 填入读取合成演示文件的任务。
  3. 确认 timeline 中的 MCP call 事件。
观测与质量门禁
展示统一 eval、运行历史、quality gate、connector health 和 recent events。
  1. 进入观测工作台。
  2. 运行 MCP 或全部 deterministic eval。
  3. 回到健康中心查看 gate 状态。
